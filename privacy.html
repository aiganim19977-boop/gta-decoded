Privacy Policy

Last updated: November 16, 2026

This policy describes how the GTA Decoded Uploader ("the app") handles data. The app is a private tool operated by the owner of the GTA Decoded YouTube channel to upload that channel's own videos.

Who can use the app

Only the channel owner. The app is not offered to the public and is not used to access anyone else's Google or YouTube account.

Data the app accesses

With the owner's consent through Google OAuth, the app uses the YouTube Data API with these permissions:

  • youtube.upload — to upload videos to the owner's GTA Decoded channel;
  • youtube.force-ssl — to set video details and post a comment with a link to the related full video on the owner's own uploads.

The app does not read viewers' personal data, private messages, subscriber lists or any data from other channels.

How data is stored

The OAuth access token is stored only on the channel owner's own computer in a local file readable by that user. It is never sent to any server other than Google's. Upload logs (video links and dates) are kept locally on the same computer.

Sharing

The app does not sell, share or transfer any Google user data to third parties, and does not use it for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file also removes the app's access.

Contact

Questions about this policy can be sent through the GTA Decoded channel's About page.
